# Pad Office Suite

Desktop-class productivity and office suite (Word, Spreadsheet, PDF Editor) built natively with Kotlin and Jetpack Compose, optimized for large-screen Android tablets like the Xiaomi Pad 7.

## Features
- **Word Processor**: Full desktop ribbon tools, Rich Text formatting, and OpenXML (.docx) support.
- **Spreadsheet Engine**: Local data handling and formula management.
- **PDF Editor**: Smooth 144Hz rendering, page navigation, and document viewing.
- **Desktop Ergonomics**: Tailored for mouse, physical keyboard shortcuts, and tablet multitasking.

## Tech Stack
- **Language**: Kotlin
- **UI Toolkit**: Jetpack Compose
- **Local Database**: Room
- **Architecture**: MVVM / Clean Architecture
